# GTA KURD (GTA V بە زمانی کوردیی سۆرانی)

> **GTA V WebAssembly Browser Port with Full Kurdish Sorani Localization & Custom Kurdish Protagonists.**

---

## 🌟 تایبەتمەندییە سەرەکییەکان (Features)

1. **زمانی کوردیی سۆرانی (Kurdish Sorani Localization)**:
   - وەرگێڕانی تەواوی مۆدەکان: **مۆدی چیرۆک** (Story Mode)، **مۆدی ئازاد** (Sandbox Mode)، **نەخشەی لۆس سانتۆس**، **نەخشەی تاقیکاری**.
   - فۆنتی تایبەتی **Vazirmatn** بۆ ڕوونی تەواوی ئەلفوبێی کوردی (ڕ، ڵ، ڤ، ێ، ۆ، گ، چ، پ، ژ) لەگەڵ ڕێکخستنی تەواوی ئاراستەی دەقەکان (**RTL**).
   - دوگمەی گۆڕینی زمان لە بەشی سەرەوەی شاشە: `[ 🌐 کوردی (سۆرانی) | English ]` کە ڕێکخستنەکان لە `localStorage` پاشەکەوت دەکات.

2. **کەسایەتییە کوردییەکان لە پێشەکیی یاری (Custom Kurdish Characters in Intro)**:
   - دانانی کەسایەتی بە جلی کوردی لە بەشی مایکڵ (`ls12_foreground_michael.webp`).
   - دانانی کەسایەتی بە جلی کوردی لە بەشی سێیەم / تریڤۆر (`ls13_foreground.webp` و `ls5_foreground.webp`).
   - هێشتنەوەی کەسایەتی یەکەم (فرانکڵین) بەبێ دەستکاری.
   - تەواوی باکگراوندی وێنەکان بە کوالێتی بەرز لادراون و بە شێوازی گرافیکی GTA V لە شاشەی لۆدینگ بە 3D Parallax دەجووڵێن.

3. **ڕێبەری کوردی لە ناو یاری (In-Game Kurdish Tactical HUD - کلیلی K)**:
   - **کۆنتڕۆڵەکانی یاری**: ڕێبەری تەواوی کلیلەکانی کیبۆرد و ماوس (جووڵە، شەڕ، سواربوون، مۆبایل، چەک، هۆڕن، کامێرا).
   - **چیرۆک و ئەرکەکان**: وەرگێڕان و ڕێنوێنی ئەرکی یەکەم (Prologue لە بانکی لودندۆرف) و ئەرکەکانی لۆس سانتۆس.
   - **کۆدە نهێنییەکان (Cheats)**: هەموو کۆدەکانی تەندروستی تەواو (`TURTLE`)، چەک (`TOOLUP`)، نەمر بوون (`PAINKILLER`)، سەیارەی خێرا (`COMET`).

## 🚀 چۆنیەتی دەستپێکردن (Quick Start)

### ڕێگای ئاسان (١ کلیک):
1. فایلی **`Launch-GTA-KURD.cmd`** بکەرەوە (Double-click).
2. یارییەکە سێرڤەری لۆکاڵ دادەگیرسێنێت و براوسەرەکەت لەسەر `http://localhost:8000/` دەکاتەوە.

### ڕێگای فەرمان (Command Line):
```powershell
cd GTA-KURD
.\runtime\python.exe serve_local.py --open
```

| **کلیکی ڕاست** | نیشانگرتن بە چەک | Aim Weapon |
| **Tab** | مینیوی دەورەیی چەکەکان | Weapon Wheel |
| **Q** | سەنگەرگرتن لە پشت دیوار | Take Cover |
| **تیر بۆ سەرەوە (↑)** | دەرکردنی مۆبایلی زیرەک | Phone |
| **R** | پڕکردنەوەی فیشەک | Reload |
| **E** | هۆڕنی ئۆتۆمبێل / کارلێککردن | Horn / Interact |
| **Space (لەناو سەیارە)** | برێکی دەستی بۆ خلیسکاندن | Handbrake / Drift |

| **V** | گۆڕینی کامێرا (ڕوانین) | Change Camera |
| **K** | کردنەوە یان داخستنی ڕێبەری کوردی | Toggle Kurdish HUD |
| **=** | نیشاندانی ڕێژەی فرەیم (FPS) | Toggle FPS Counter |

## ⭐ کۆدە نهێنییەکان (Cheats)

لە کاتی یاری کلیلی **`~`** (یاخود مۆبایل) دابگرە و کۆدەکان بنووسە:

- `PAINKILLER` - نەمر بوون بۆ ماوەی ٥ خولەک (Invincibility)
- `TURTLE` - تەندروستی تەواو و قەڵغانی گوللەبەند (Max Health & Armor)
- `TOOLUP` - دەستکەوتنی هەموو چەکەکان بە فیشەکی تەواوەوە (All Weapons)
- `LAWYERUP` - کەمکردنەوەی ئەستێرەی پۆلیس (Lower Wanted Level)
- `FUGITIVE` - زیادکردنی ئەستێرەی پۆلیس (Raise Wanted Level)
- `CATCHME` - ڕاکردنی زۆر خێرا (Fast Sprint)
- `SKYFALL` - فڕین و بەربوونەوە لە ئاسمان (Skyfall)
- `COMET` - هێنانی ئۆتۆمبێلی وەرزشی کۆمێت (Spawn Comet)
- `RAPIDGT` - هێنانی ئۆتۆمبێلی ڕاپید GT (Spawn Rapid GT)
- `ROCKET` - هێنانی ماتۆڕی وەرزشی PCJ-600 (Spawn PCJ-600)

ئەگەر داتای تەواوی یارییەکەت (بوخچەی `mirror`) لە شوێنێکی ترە:
فایلی **`Setup-Mirror.cmd`** بکەرەوە و ناونیشانی بوخچەی `mirror` داخڵ بکە، ڕاستەوخۆ دەبەسترێتەوە.

### مەرجەکانی سیستەم (Requirements)
- براوسەرێکی خاوەن پاڵپشتی **WebGPU** (Chrome 113+ یان Edge 113+ یان Brave).
- کارتێکی گرافیک (GPU) کە پاڵپشتی لە DirectX 12 یان Vulkan یان WebGPU بکات.
- ڕامی پێشنیارکراو: **8 GB** یان زیاتر.
